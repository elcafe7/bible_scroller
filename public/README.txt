Scroll (bible_scroller) 0.1.0 — offline copy

Editions: Geneva 1599, KJV 1611 (both with Apocrypha), KJV Oxford 1769 (66 books).
Commentary: none, Matthew Henry, or Calvin.

Open it
  1. Double-click index.html. Firefox (and usually Safari) runs it
     directly from the folder.
  2. Chrome and Edge block local data files opened as file://.
     If you see "Bible data missing or unreadable", serve this folder
     instead (still fully offline):
        python3 -m http.server 8000      then open http://localhost:8000/
     or npx serve .                       then open the printed address

Use it
  Choose a passage (edition, book, chapter, verse), commentary, speed,
  text size, theme, and Vertical or Ticker mode, then press Start.
  Esc, Space, or a double-tap returns to settings; Resume continues.
  Settings are remembered in this browser only.

No network access, accounts, or server code. Bible text and commentary
are public domain.
